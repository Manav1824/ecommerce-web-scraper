# 🛒 E-Commerce Data Extractor

A robust Python web scraping tool designed to extract product catalogs from e-commerce websites and structure the data into analysis-ready CSV files. 

## Features
- **Automated Extraction:** Scrapes product titles, pricing, and stock availability.
- **Header Masking:** Utilizes custom User-Agents to bypass basic bot-protection.
- **Clean Output:** Automatically formats raw HTML data into a clean, ready-to-use `CSV` file.

## Tech Stack
- Python 3.14
- `requests` (HTTP requests)
- `BeautifulSoup4` (HTML parsing)
- `csv` (Data structuring)

*Built as a scalable template for fixed-price data extraction and lead generation projects.*
